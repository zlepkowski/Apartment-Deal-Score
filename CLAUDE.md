# DealScore — notes for Claude

Before any UI, copy, or data-handling work, read docs/DESIGN_GUIDELINES.md and follow it.
The last audit against it is docs/DESIGN_AUDIT.md.

## Project
- Static NYC apartment site: vanilla ES modules in `assets/js/`, Tailwind via CDN, no npm.
- Every listing is priced against StreetEasy's median asking rent (`assets/js/data/market.js`,
  generated by `scripts/import-streeteasy.mjs`). DealScore is not affiliated with StreetEasy.

## Commands
- `node build.mjs` — rebuild `dist/dealscore.js` after editing anything in `assets/js/`
  (new modules must be added to `order[]` in `build.mjs`; all modules share one scope,
  so top-level names must be unique across files).
- `node --test` — engine tests.
- `node scripts/import-streeteasy.mjs` — import StreetEasy CSVs from `data/streeteasy/`
  (see `data/streeteasy/README.md`).

## Rules
- Never scrape or automate requests to StreetEasy; data comes from manual Data Dashboard downloads.
- Raw StreetEasy CSVs stay out of git (public repo); only the generated latest-month figures are committed.
- Legal pages are drafts with `[[TODO]]` placeholders until the owner and a lawyer review them.
